# Configuration

After flashing, configure CleverCoffee using the controller's web interface.
Exact options depend on the firmware version and the hardware features in your
build.

Start with [first-time configuration](first-setup.md), then adjust only the
features you intend to use. The upstream
[configuration reference](https://github.com/rancilio-pid/clevercoffee/blob/master/CONFIG_REFERENCE.md)
lists parameter names, defaults, and constraints.

## Common configuration areas

- Brew and steam temperature targets and control settings.
- Brew mode, brew-by-time, brew-by-weight, and pre-infusion.
- Switch types and optional sensors.
- Scale calibration and Bluetooth scale settings.
- Wi-Fi and MQTT connectivity.
- Display, standby, and backflush preferences.

Save a copy of the configuration before making substantial changes, where
backup and restore options are available in your firmware.
