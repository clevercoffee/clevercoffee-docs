# Frequently asked questions

## Do I need PlatformIO to install CleverCoffee?

No. Use the [Web Flasher](../installation/index.md) for standard installation.
PlatformIO is for firmware development.

## Can I install it in my machine?

Firmware support includes Rancilio Silvia, Gaggia, and Quickmill machines, but
compatibility depends on the exact machine and board revision. Check
[compatibility](../hardware/compatibility.md) before building.

## Is pressure profiling supported?

This documentation covers pressure measurement only. It does not document
pressure profiling as a supported feature.

## Where do I change settings?

Use the firmware's web interface. For parameter definitions, consult the
current upstream [configuration reference](https://github.com/rancilio-pid/clevercoffee/blob/master/CONFIG_REFERENCE.md).

## Where can I ask for help?

Check [Troubleshooting](../troubleshooting/index.md), then ask in the
[CleverCoffee Discord](https://discord.gg/Kq5RFznuU4). Include your firmware
version, machine model, and PCB revision, but do not share credentials.
