# Hardware overview

CleverCoffee is intended for builders who install a controller in their own
espresso machine. Hardware choice, wiring, and available functions depend on
the machine and the exact board revision.

## Plan the build

- Identify the espresso-machine model and revision.
- Identify the controller PCB and its revision; use its matching build and
  assembly instructions.
- Confirm which optional sensors, switches, display, and scale are present.
- Review [compatibility](compatibility.md) and the
  [electrical safety requirements](../getting-started/safety.md) before
  starting work.

The software repository documents support for Rancilio Silvia, Gaggia, and
Quickmill machines, but support for a machine family does not guarantee that
every model or board combination is compatible.

## Builder responsibility

This documentation does not provide a universal wiring diagram. Machine
circuits and PCB revisions differ; follow the instructions for the exact
hardware you have. The CleverCoffee project also notes that community support
is primarily for its own PCBs.

See [Troubleshooting](../troubleshooting/index.md) if a completed, safely
assembled controller does not behave as expected.
